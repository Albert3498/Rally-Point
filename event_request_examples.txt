EVENT REQUEST EXAMPLES
======================

All examples are JSON bodies for:  POST /event-requests/
(send the header  Authorization: Bearer <access_token>  from /login/)

Dates must be in the future and include a timezone (+00:00, +02:00, Z ...).
If the examples below are in the past when you read this, move the dates forward.

Server-generated (never send these): id, requester_id, status, review_note,
created_at, updated_at.

--------------------------------------------------------------------------
INVALID EXAMPLES (these return 422 with the field name in the error)
--------------------------------------------------------------------------

A) Title too short (min 5 characters)  -> error on "title"
   "title": "Hi"

B) Description too short (min 20 characters)  -> error on "description"
   "description": "Clean the beach"

C) Unknown category  -> error on "category"
   "category": "party"
   (allowed: environment, education, community, animal_welfare, charity, other)

D) Start date in the past  -> error on "start_datetime"
   "start_datetime": "2020-01-01T09:00:00+00:00"

E) End before start  -> error on "end_datetime"
   "start_datetime": "2027-03-20T13:00:00+00:00",
   "end_datetime":   "2027-03-20T09:00:00+00:00"

F) Date without timezone  -> error on "start_datetime"
   "start_datetime": "2027-03-20T09:00:00"

G) Zero volunteers  -> error on "volunteers_needed"
   "volunteers_needed": 0

H) Bad email  -> error on "contact_email"
   "contact_email": "not-an-email"

I) Blank required value (spaces only, trimmed to empty)  -> error on "location"
   "location": "     "

J) Trying to set a server-controlled field  -> error on "status" / "requester_id"
   "status": "approved"
   "requester_id": 1


--------------------------------------------------------------------------
ADMIN REVIEW EXAMPLES
--------------------------------------------------------------------------

PATCH /admin/event-requests/{id}/review/     (admin token required)

Approve:
{
  "status": "approved",
  "review_note": "Looks good, thanks for organising this."
}

Reject:
{
  "status": "rejected",
  "review_note": "Duplicate of an existing event on the same date."
}

Notes:
- "status" must be "approved" or "rejected" ("pending" is not allowed here).
- "review_note" is optional (max 2000 characters).
- A request can only be reviewed once; a second review returns 409.
